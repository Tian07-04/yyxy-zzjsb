SUPABASE · 接入指引

把官网接到云端自动同步

按下面 5 步操作，约 5 分钟完成。接好后，你登录后台改内容，全站访客立即看到最新版，不用再找我重新部署。

① 开项目→ ② 拿密钥→ ③ 跑建表→ ④ 填配置→ ⑤ 重新部署

1注册并新建 Supabase 项目

Supabase 是免费云端数据库，官网直接注册，无需信用卡。

  • 打开 https://supabase.com ，点右上角 Start your project 用 GitHub 或邮箱注册登录。
  • 登录后进入控制台，点 New project（新建项目）。
  • 填写：项目名称（如 hhxy-music-org）、设置数据库密码（记一下，后面基本用不到但别忘）、地区选离国内近的（如 Singapore / Tokyo），最后点 Create new project。
  • 等待约 1–2 分钟，项目创建完成会自动进入项目首页。
✅ 免费套餐（Free）足够本网站使用：存储 500MB、每月 5 万次请求，完全够一个学院部门官网。

3在 SQL Editor 执行建表脚本

只跑一次，自动建好「站点内容表 + 党建/团建文章表」并设好权限。

  • 左侧菜单点 SQL Editor → New query。
  • 把项目里的 supabase-schema.sql 全部内容粘贴进去（也在下方折叠代码里）。
  • 点右上角 Run 执行，出现 Success 即建表完成。

📄 脚本文件就在你网站根目录：supabase-schema.sql。下面是它的核心内容：

-- 站点静态内容（除文章外） create table if not exists site_content ( id text primary key, content jsonb not null, updated_at timestamptz default now() ); -- 党建 / 团建 文章 create table if not exists articles ( id uuid primary key default gen_random_uuid(), section text not null, -- 'party' 或 'league' title text, date text, cover text, body text, category text default 'news', -- news/notice/publicity created_at timestamptz default now() ); -- 开启行级安全 + 任何人可读，仅后台密码可写 alter table site_content enable row level security; alter table articles enable row level security; -- （脚本内已写好 select 公开、写入需 x-admin-key = 后台密码 的策略）
💡 脚本里的写入密码默认是 88888888，必须和 config.js 里的 ADMIN_PASSWORD 一致。如果你改了后台密码，记得同步改脚本第 37、41 行的 '88888888' 再执行一次。

4把密钥填进 config.js

打开网站目录下的 assets/js/config.js，替换两个空值。

// assets/js/config.js （改前两个值即可） window.APP_CONFIG = { SUPABASE_URL: "https://abcd1234.supabase.co", // ← 填第②步的 Project URL SUPABASE_ANON_KEY:"eyJhbGci...很长一串", // ← 填第②步的 anon key ADMIN_PASSWORD: "88888888" // 后台密码，可改 };
⚠️ 填的时候只替换双引号 "" 里面的内容，不要删掉引号和外面的逗号。填错会导致后台连不上。

你填好后把这个文件发我（或直接告诉我「已填好，重新部署」），我来做第 ⑤ 步。

5重新部署 + 验证同步

我把带密钥的版本重新部署到云端，你验证「改一条 → 全站即时更新」。

  • 部署完成后，打开 /admin.html 用密码登录后台。
  • 进入「党建工作」或「团建工作」标签页，新增一篇文章并点「保存全部」。
  • 打开官网前台（非后台页面），刷新 —— 你刚发的文章应该立即出现，无需任何额外操作。
  • 换手机/换浏览器打开官网，也能看到，说明已真正云端同步 ✅。
✅ 至此完成全自动同步。以后你只用在后台编辑 → 保存，线上访客永远是最新版。
